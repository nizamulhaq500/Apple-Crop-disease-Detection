# Apple Crop Disease Detection

A deep learning project using PyTorch to detect and classify diseases in apple crops from images. The project explores a custom-built CNN (trained in notebooks) and provides a pipeline for fine-tuning a ResNet18 model.

## Project Structure

```
├── .gitignore
├── README.md
├── notebooks/                # Jupyter notebooks for data exploration
│   └── 01_explore_data.ipynb
├── src/                      # Source code for the pipeline
│   ├── data_loader.py        # Data loading and transformation logic
│   ├── data_split.py         # Script to split data into train/val/test sets
│   ├── evaluate.py           # Evaluation script for the trained model
│   ├── model.py              # ResNet18 model definition and modifications
│   └── train.py              # Main training loop
├── data/                     # Directory for dataset (ignored by git)
│   └── split/                # Train/Val/Test splits generated by data_split.py
└── models/                   # Directory where trained models are saved
```

## Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nizamulhaq500/Apple-Crop-disease-Detection.git
   cd Apple-Crop-disease-Detection
   ```

2. **Set up a virtual environment (Recommended):**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows use: .venv\Scripts\activate
   ```

3. **Install Dependencies:**
   Ensure you have PyTorch and Torchvision installed. You can install them via pip:
   ```bash
   pip install torch torchvision
   ```
   *(Note: Depending on your hardware, you may want to install the CUDA or MPS specific versions of PyTorch).*

## Usage Pipeline

### 1. Prepare the Data
Ensure your raw data is placed correctly in the `data/` folder, then run the split script to create `train`, `val`, and `test` directories:
```bash
python src/data_split.py
```

### 2. Train the Model
The training script loads the data, initializes a pre-trained ResNet18 model, fine-tunes it, and saves the best model to the `models/` directory:
```bash
python src/train.py
```
*The script automatically selects the best available device (CUDA, MPS, or CPU).*

### 3. Evaluate the Model
Once training is complete, you can evaluate the model's performance on the test set:
```bash
python src/evaluate.py
```

## Model Details
This project includes two models:

1. **Custom CNN (from Notebook)**
   - **Architecture:** A 3-layer Convolutional Neural Network with Max Pooling and Adaptive Average Pooling, followed by a fully connected classifier with Dropout.
   - **Status:** Defined and trained entirely in `notebooks/01_explore_data.ipynb`.
   - **Weights:** Saved locally at `models/custom_cnn_best.pth`.

2. **ResNet18 (from Pipeline)**
   - **Architecture:** ResNet18 (Pre-trained on ImageNet1K_V1)
   - **Modifications:** Early layers are frozen; the final fully connected layer is replaced and trained to match the specific number of crop disease classes.
   - **Data Augmentation:** Random Horizontal Flips, Random Rotations, and Normalization are applied during training to prevent overfitting.
